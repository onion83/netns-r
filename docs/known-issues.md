# 已知问题与后续工作

本清单基于 2026-11-25 代码审查。除文档与构建入口整理外，下列运行问题尚未修复。

## 发布前优先处理

| 问题 | 当前影响 | 修复方向 |
| --- | --- | --- |
| dry-run 有副作用 | 环境检查、恢复、clean 和无 DNS 分支仍可能修改系统 | 将所有变更纳入统一执行计划，增加无副作用回归测试 |
| 活跃实例误判为残留 | 第二实例可能清理第一实例的资源 | 独占锁、可靠的进程身份和资源归属 |
| 名称及配置验证不足 | 路径拼接、名称重复、接口长度和无效 CIDR 未被完整拦截 | 在任何系统变更前完成验证 |
| 启动失败没有统一回滚 | 部分网络、规则或服务残留 | 跟踪已创建资源并按顺序回滚 |
| 重启退避溢出 | 长期失败后 panic 或等待时间异常 | 限制指数并使用饱和计数 |
| 配置与行为不一致 | 默认日志未继承、命名空间 env 未应用 | 明确继承语义并补测试 |
| 清理及命令错误处理不一致 | 部分失败仅记录或忽略，重复清理可能报错 | 区分不存在、失败和成功，保留错误证据 |
| 自动化验证不足 | 当前测试不能证明网络生命周期正确 | Linux 隔离测试、失败注入、CI |

发布整理还包括确认 MIT 版权声明并补 LICENSE、设置远程仓库，以及由用户确认文档和文件清理结果。当前没有推送到 GitHub。

## 后续候选功能

- VLAN 子接口：在设计评审后确定创建、复用和清理归属；
- 服务健康检查、依赖顺序和状态可观测性；

- nftables 或规则集合优化；
- 结构化 dry-run 输出、指标和必要的状态持久化。

性能优化应先测量，再确定方案；不保留原报告中未经复测的百分比收益。
